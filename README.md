# Aluguel de Carros (Brasil)

Site institucional da AlugueldeCarros.org — locação de veículos com atendimento via WhatsApp.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Rotas

- `/` — Início
- `/frota` — Frota & Tarifas
- `/empresa` — A Empresa
- `/terceirizacao` — Terceirização de Frota
- `/promocoes` — Promoções
- `/contato` — Contato
